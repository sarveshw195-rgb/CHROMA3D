HOW THIS WAS MADE

CHROMA 3D, MADE "OURS"

Before building this, we reverse-engineered the real Microsoft Paint 3D with REA (a reverse-engineering toolkit driven through OpenCode) and rebuilt its core spirit for the browser.

  • Target: PaintStudio.View.exe — Paint 3D's renderer, v6.1907.29027.0, 3.3 MB x64 PE
  • 9,738 procedures recovered · 3,001 strings · Ghidra 12.1.4 analysis engine
  • Discovered it's a .NET Native compiled UWP app — an extra tdb metadata segment at 0xff00000000 gave it away
  • Class map read straight from the compiled metadata: ToolBase, SceneTool, TextTool, MenuGroup, OutputCentre3D, MixedRealityMainPage
  • Its 3D pipeline talks to Direct3D; the build even ships Holographic hooks (HolographicApplicationPreview)
  • Our take swaps D3D for Three.js / WebGL: strokes become tubes along Catmull-Rom curves; emoji stickers ride billboard sprites; objects are parameterised primitives — the "stickers & 3D objects" idea from the original, made ours
  • v2: category tabs, emoji & object placement, unified undo across everything, transparent-PNG export, artwork save/open (.chroma files), keyboard shortcuts, touch pinch

Evidence: REA evidence records (sha256 d7ae0734…45f3339f of the original binary); analysis snapshot retained. No Microsoft assets used — everything here is ours. — made ours ✦

Paint in space · quick guide
  • Draw with the left mouse on any depth. Orbit with right-drag, zoom with the wheel.
